# Antipasto Pro Webfonts

Vor dem Livegang bitte die lizenzierten Webfont-Dateien mit exakt diesen Namen ablegen:

- `AntipastoPro-Regular.woff2`
- `AntipastoPro-Medium.woff2`
- `AntipastoPro-Demibold.woff2`

Die `@font-face`-Definitionen sind bereits in `app/globals.css` vorbereitet. Antipasto Pro ist eine kommerzielle Schrift von Zetafonts; die Dateien werden deshalb nicht aus einer inoffiziellen Quelle übernommen.
